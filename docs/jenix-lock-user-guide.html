Jenix Lock — User Guide

Control your Jenix smart locks from your phone through the Jenix Lock gateway: open and close, manage users and fingerprints, share one-time door codes, get low-battery alerts and download attendance reports.

Jenix Lock app
on your phone
→home Wi-Fi
Jenix gateway
small box, plugged in near the door
→Bluetooth
Your lock(s)
one gateway, several locks

What you need

  • The Jenix gateway and a good 5 V / 2 A USB adapter (weak phone chargers can make it restart).
  • Your home or office 2.4 GHz Wi-Fi name and password (5 GHz-only networks are not supported).
  • An Android phone with the Jenix Lock app.
  • For each lock: its connection password if it was set up before — or a factory-reset lock.
Wi-Fi extenders: if your Wi-Fi uses an extender/repeater with the same network name, the phone and the gateway may land on different ones and not see each other. Prefer one router (or a proper mesh system) for the gateway's Wi-Fi.
Place the gateway within about 5–8 m of the locks with few walls in between, and away from metal door frames. The app shows the signal strength so you can find a good spot.

1 · Set up the gateway

  1. Plug in the gateway. A new gateway blinks purple and creates a Wi-Fi network called JenixLock-XXXX.
  2. In the app tap + → Set up new gateway.
  3. Open your phone's Wi-Fi settings and join JenixLock-XXXX. If Android says "No internet", choose Stay connected. Return to the app and tap I've joined.
  4. Tap your Wi-Fi name in the list, enter its password (tap the eye icon to check it), give the gateway a name and tap Connect gateway.
  5. The gateway joins your Wi-Fi and the phone returns to it automatically. The gateway light turns blue and the app shows it as online.
You never type an IP address. If the router later gives the gateway a new address, the app finds it again by itself.

2 · Add a lock

  1. Touch the lock's keypad to wake it, then on the gateway card tap Scan & add a lock.
  2. Pick your lock in the list (it shows as Lck1_…) and give it a name, e.g. Main door.
  3. Choose:
    • New / reset lock — the app sets a new 6-digit connection password (type it twice and keep it safe; you need it to add this lock again).
    • Already set up — enter the lock's existing 6-digit connection password.
  4. Pick the time zone (India is the default) and tap Connect lock. The app checks the password with the lock before saving.
  5. Choose who opens the door from the app: tap a user from the list and enter that user's keypad PIN.
Connection password ≠ keypad PIN. The connection password is only for the app and gateway. A keypad admin PIN will not work here. If you don't know a lock's connection password, factory-reset the lock and add it as a new lock (this erases its users and fingerprints).

Open & close

  • Open the lock from the list and tap Unlock or Lock. With auto close on, the button counts down "Closes in 10s".
  • The Connection card shows the live signal between lock and gateway (Bluetooth) and gateway and router (Wi-Fi): Excellent / Good / Fair / Weak. It measures for one minute to save the lock battery — tap Measure again to refresh.
  • The 🔋 badge on the lock list shows its battery; it turns red below 25 %.
  • Tap the lock name at the top to rename it.

Users, fingerprints, cards & PINs

In the Users tab each person shows three icons — fingerprint, card and PIN — that turn green when enrolled. Tap a user to:

  • Rename them (e.g. staff names for the attendance report).
  • Add a fingerprint: tap Add finger, then place the same finger on the lock's sensor, lift and repeat about 3 times when the lock beeps.
  • Add a card: tap Add card and hold the card flat on the keypad.
  • Set or change the PIN (numbers only, 4–16 digits). If the lock says the PIN can't be used, simply choose a different one.
  • Access validity: Permanent, or Custom dates, daily hours and days — for example staff Monday–Saturday 09:00–18:00. Expired users are shown in red.
  • Delete the user and all their fingerprints, cards and PIN.

Temporary door code (one-time PIN)

Give a visitor or delivery person a 6-digit code without adding them as a user. The code is valid only for the current 5-minute window and works even if the internet is down.

  1. On the Control tab, enter the lock's keypad admin PIN once (the PIN the admin user types on the keypad — not the connection password) and tap Generate code.
  2. Tap WhatsApp or SMS (or More…) to send it. The message includes the instructions.
  3. The visitor wakes the keypad, presses *, enters the code, then presses # — the lock opens.
Codes use the lock's time (its time zone is set when the lock is added), so they work even if your phone is set to another time zone. Keep the phone's date & time on automatic. A code only works during the 5-minute window shown under it.

Records & attendance (Excel)

  • The Records tab lists every opening: Keypad PIN, Fingerprint, Card, Phone app and Auto close, with the user and time. Refused attempts are marked.
  • Choose Today / 7 / 30 / 90 days and tap Download Excel (attendance). The file has three sheets:
    • Attendance — per person per day: first IN, last OUT, hours, number of entries.
    • Summary — per person: days present and total hours (for salary/payroll).
    • Full log — every event.
  • Share it by WhatsApp, e-mail or Drive straight from the share menu.

Auto close

Lock → Settings → Auto close the lock: pick 5s / 10s / 15s / 30s / 1 min (or 3–60 s) and tap Save.

  • Also close after app unlock (on by default): after you unlock from the app, the gateway locks the door again itself after that time — this works without a door magnet.
  • Openings with keypad PIN, fingerprint or card are closed by the lock itself, which needs its door magnet fitted to see that the door is shut.
Auto close locks after the set time even if the door is still open. Choose a time long enough to walk through.

Normally open

Keep the door unlocked during set hours — for example an office during working hours. Lock → Settings → Normally open: turn it On, set From–To (or Whole day) and the days, then Save.

Anyone can open the door during this time. Auto close does not act inside the window. To lock manually during it, press and hold 0 on the keypad. If you save Auto close while Normally open is on, the app offers to turn Normally open off.

Low-battery alerts

  • The gateway checks every lock's battery a few times a day.
  • Below 25 % the phone alerts you with sound and vibration — inside the app, and as a notification when the app is in the background or closed (while the phone is on the same Wi-Fi as the gateway).
  • Allow notifications when the app asks. Use Settings → Low-battery alerts → Test alert to check sound and vibration, or Check batteries now.

Gateway settings & firmware updates

Tap the ⚙ on the gateway card:

  • Gateway firmware: shows the installed version and the version included in your app. When the gateway card shows update available, tap Update gateway. Keep the app open on the same Wi-Fi for about a minute. Your Wi-Fi, locks and settings are kept; if anything goes wrong the gateway keeps its current firmware.
  • Radio power: Normal or High for Wi-Fi and Bluetooth. Use High only with a good 5 V / 2 A adapter; if the gateway restarts from a power dip it lowers the power by itself.
  • Remove gateway removes it from this phone only.

Troubleshooting

ProblemWhat to do
Gateway shows offlineCheck the phone is on the same Wi-Fi as the gateway. After the gateway restarts, give it up to 2 minutes. Tap the offline label to check again.
Offline only sometimes, or only from some phonesA Wi-Fi extender / repeater using the same network name often blocks phones connected to it from reaching devices on the main router (and the other way round). Set the extender to access point / mesh mode, turn off its client isolation, or give it its own network name and keep the phone and the gateway on the same one.
"Lock not reachable" / not connectedTouch the lock's keypad to wake it and try again. If the signal shows Weak, move the gateway closer.
"Wrong connection password"This is the lock's connection password, not a keypad PIN. If unknown, factory-reset the lock and add it as New / reset lock.
"This PIN can't be used"Choose a different PIN. The user keeps their old PIN until a change succeeds.
"Lock refused user's PIN"Lock → Settings → App opens the door as: pick the right user and enter their correct PIN.
Door does not lock by itselfFor app openings turn on Also close after app unlock. For keypad/finger/card openings fit the door magnet. Check Normally open is off.
Temporary code doesn't workUse it within its 5-minute window; press * before and # after the code; check the admin PIN entered in the app.
No battery notificationsAllow notifications for Jenix Lock in Android settings; keep the phone on the gateway's Wi-Fi.
Start the gateway setup againPress the gateway's RESET button 10 times, about once per second (white blink each press, amber from the 5th). It restarts blinking purple. This clears only the gateway — the locks' users and fingerprints are kept.

Safety

  • Keep a physical key or keypad PIN as a backup way in.
  • Keep the lock's connection password and admin PIN private; anyone with them can control the lock.
  • Replace lock batteries when the app warns — the lock keeps working on its keypad, fingerprint and card even when the gateway or Wi-Fi is down.
